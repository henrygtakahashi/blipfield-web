# blipfield-web

Public pages for Blipfield: Bluetooth Hunt, served by GitHub Pages.

- `privacy.html`: the privacy policy linked from the Play listing, at
  https://henrygtakahashi.github.io/blipfield-web/privacy
- `index.html`: a minimal landing page.

The policy must match what the app does. Update it, and its effective date,
before shipping any change that stores or sends new data.
